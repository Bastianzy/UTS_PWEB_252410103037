# CashFlow - Aplikasi Pencatatan Keuangan (UTS Pemrograman Web)

Aplikasi web manajemen arus kas pribadi (*Personal Cash Flow*) yang dibangun menggunakan arsitektur **Laravel MVC Murni** tanpa database fisik, memanfaatkan *Session* untuk pengelolaan data dinamis, serta didesain menggunakan **Tailwind CSS**.

## Fitur Utama & Alur Aplikasi
1. **Simulasi Login:** Masuk menggunakan nama pengguna/username secara personal.
2. **Dashboard:** Menampilkan ringkasan total saldo, pemasukan, dan pengeluaran secara real-time yang dimulai dari nilai **Rp 0** sebelum ada transaksi.
3. **Pengelolaan Transaksi:** Form input dinamis (keterangan, kategori bebas, nominal, dan tipe arus) dengan validasi anti-minus, terhubung langsung ke tabel riwayat menggunakan *Session* array.
4. **Halaman Profil:** Menampilkan informasi detail akun berdasarkan pengguna yang sedang aktif.
